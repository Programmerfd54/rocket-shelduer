# Роли без HQ и без «городов» — заметки к деплою

Миграция `20261007100000_remove_hq_admin_role` (применить: `npx prisma migrate deploy`):

- **Роли.** `HQ_ADMIN` удалена: все такие пользователи и приглашения переведены в `LEAD_SUP`; учётная запись
  с логином `admin` тоже получает `LEAD_SUP`. Итоговый enum `Role`: `LEAD_SUP`, `SUP`, `ADM`, `MEMBER`.
- **Города больше не используются.** Таблицы `City`, `CityMember`, `CityOsnovyLink`, `CityWorkspaceOffer`,
  `CitySystemSetting` и колонки `cityId` оставлены в БД (legacy), код их не читает и не пишет.
  Видимость пространств — как до «городов»: свои + назначенные (`WorkspaceAdminAssignment`).
- **Контент.** Городские справка (основной текст, разделы, каталоги с инструкциями/FAQ), переопределения
  официальных шаблонов и настройки города скопированы в глобальные записи, если глобального аналога не было
  (без дублей; городские строки не удалены). Приложение работает только с глобальными записями.
- **Безопасность данных.** FK `WorkspaceConnection.cityId` теперь `ON DELETE SET NULL` (удаление строки `City`
  не удаляет пространства). Удалён «забытый» уникальный индекс `OfficialTemplateOverride(templateId, scope)`,
  которого нет в `schema.prisma`.
- **Приглашения.** `InviteToken` получил `volunteerExpiresAt` / `volunteerIntensive` — срок доступа волонтёра
  переносится в пользователя при регистрации.
