# UI-гайд (Notion / Linear / Supabase / Figma)

Цель: спокойный, плотный, «рабочий» интерфейс. Никакого «AI-вида»: без пастельных цветных блоков,
градиентов, цветных полос слева у карточек, кругов-иконок с лампочками, огромных скруглений и теней.

## Токены (app/globals.css) — только семантические классы
- Фон страницы `bg-background`, панели/карточки `bg-card` + `border` (1px). Приглушённый фон — `bg-muted/50`.
- Текст: `text-foreground`, вторичный `text-muted-foreground`. Акцент — `primary` (зелёный), использовать **только** для главного действия, активного пункта и ссылок.
- Статусы: `success` / `warning` / `destructive` / `info` — через `Badge` (variants) или `text-*`/`bg-*` с низкой насыщенностью (`bg-emerald-500/10 text-emerald-700 dark:text-emerald-300`). Не красить целые блоки.
- Радиусы: поля и кнопки `rounded-md`, карточки/диалоги `rounded-lg`. Не использовать `rounded-2xl`/`rounded-3xl`/`rounded-full` (кроме аватаров и точек статуса).
- Тени: нет у карточек. Только у поповеров/диалогов (`shadow-md` уже в компонентах).
- Градиенты, `backdrop-blur`, `hover:-translate-y`, анимации «пружиной» — не использовать.
- Цветные «полоски» слева у карточек (`border-l-4`, `w-1 bg-*`) — убрать; различать группы заголовком и разделителем.

## Типографика
- Шрифт Inter (var `--font-sans`), моно — JetBrains Mono для URL/логинов/кода.
- Заголовок страницы `text-xl font-semibold tracking-tight`, подзаголовок `text-sm text-muted-foreground`.
- Заголовок секции `text-sm font-semibold`, подписи полей `text-sm font-medium`, подсказки `text-xs text-muted-foreground`.
- Никаких `uppercase tracking-[0.2em]` «оверлайнов».

## Компоненты (components/ui/*)
- Кнопки: высота 32–36px (`size="sm"` в тулбарах и строках, `default` в формах). Главная — `variant="default"`, вторичная — `outline`, опасная — `destructive`; иконка слева `size-4`.
- Поля: высота 36px, `border-input`, фокус — кольцо `ring`. Всегда `Label` над полем, ошибка под полем `text-xs text-destructive`, подсказка `text-xs text-muted-foreground`.
- Таблицы/списки: строка 40–48px, `border-b`, hover `bg-muted/40`, без обёрток-карточек у каждой строки.
- Пустые состояния — `components/common/EmptyState` (иконка + заголовок + одна строка + действие).
- Загрузка — `Skeleton` на месте контента, а не спиннер на всю страницу.
- Диалоги подтверждения опасных действий — `AlertDialog` (не `window.confirm`), с названием объекта и последствиями.

## UX-правила
- Любое действие пользователя заканчивается тостом (`sonner`): успех — коротко, ошибка — что случилось + что делать.
  Для долгих операций — `toast.loading` → `toast.success/error` по `id`.
- Валидация на клиенте до запроса (zod / ручная): ошибки у поля, кнопка отправки блокируется при невалидной форме,
  при отправке показывает спиннер и блокируется от повторного нажатия.
- Все тексты — по-русски, без жаргона. Роли: Lead_SUP, SUP, ADM, MEMBER (волонтёр).
- Тач-цели ≥ 36px, адаптив до 360px, фокус-кольцо видно, `aria-label` у иконочных кнопок.
- Не ломать существующие данные-атрибуты, ID, маршруты и API-контракты, если задача этого не требует.
